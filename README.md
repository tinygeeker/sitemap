## ✨ 项目特性

- 🎨 **优美界面**：手风琴导航风格，响应式设计，适配各种设备
- 🌌 **动态背景**：星空粒子效果和光线特效，营造科技感氛围
- 📁 **分类清晰**：包含常用网址、在线娱乐、在线考证、效率工具、冷门网站、软件下载等分类
- 🔍 **快速查找**：直观的分类导航，快速找到所需网站
- 🚀 **性能优化**：Vue 3 + Element Plus 构建，加载速度快
- 🌐 **丰富资源**：收录了大量实用网站，满足各种需求

## 🛠️ 使用方法

### 1. 克隆项目
```bash
git clone https://github.com/tinygeeker/perfectSitemap.git
cd perfectSitemap
```

### 2. 安装依赖
```bash
npm install
```

### 3. 启动开发服务器
```bash
npm run tinygeeker
```

### 4. 构建生产版本
```bash
npm run build
```
